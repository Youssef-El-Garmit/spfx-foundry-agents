# Security

Foundry Agents runs entirely in the user's browser. It stores no secrets and calls Azure AI Foundry, Microsoft Graph and SharePoint with the signed-in user's delegated Microsoft Entra token.

To report a vulnerability, please do **not** open a public issue. Use GitHub's private vulnerability reporting ("Report a vulnerability" in the Security tab) or write to the maintainer via https://ktifa.com/contact. We aim to answer within 5 working days.
